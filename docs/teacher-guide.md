# Section layouts — teacher guide

A Designer course draws each section's activities using a **section layout**. You
can set one for the whole course and override it on any individual section, so a
course can open with a row of cards and then settle into plain lists further down.

## Choosing a layout for one section

Turn editing on, open the section's edit menu and pick **Change section layout**.

| Layout | What you get |
| --- | --- |
| **Default (custom sections)** | The standard Moodle look: the same activity rows you would see in a Custom sections course |
| Text links | Just the activity names, as links — compact, good for long reference sections |
| List | Designer's list, with room for descriptions and completion information |
| Cards | A tile per activity, with images if you have set them |
| Circles, Horizontal circles | Available with Designer Pro |

The layout applies to that section only. Sections you never touch follow the
site-wide default your administrator set.

### When to use Default

**Default (custom sections)** is the one to pick when you want the section to look
like an ordinary Moodle course. It uses Moodle's own activity markup, so
everything behaves exactly as students expect — availability notices, completion
conditions, activity dates and the edit menus all sit where they normally do.

It is a good choice when you are using Designer for the course header, the
progress display or the course index, and you do not want the activity list itself
to look unusual.

## Section width

If your course shows one section per page, each section can also take a share of
the page width — full width, a half, a third, a quarter or a fifth, set separately
for desktop, tablet and mobile. That is under the same section settings, as
**Desktop width**, **Tablet width** and **Mobile width**.

If you cannot see those fields, either the course shows all sections on one page —
where they always span the full width and the setting would do nothing — or your
administrator has switched the feature off.

## Something is missing from the section settings

Designer's features can be switched off site-wide by an administrator, and a
feature that is off takes its settings out of the form with it. Nothing you have
already set is lost: if the feature comes back, so do your settings, exactly as
they were.

If a setting you need is not there, ask your administrator to check
*Site administration ▸ Plugins ▸ Course formats ▸ Designer ▸ Manage features*.

## Copying a course keeps your layouts

Duplicating, copying, backing up and restoring a course all carry the section
layouts with them, along with widths, estimated times and every other Designer
setting. A copied course looks like the course you copied.
